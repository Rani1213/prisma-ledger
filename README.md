# Prisma Ledger

Prisma Ledger is a lightweight DeFi and open finance smart contract project built on OPN Testnet.

## Overview

Prisma Ledger explores transparent and decentralized financial interaction using EVM-compatible smart contracts.

## Features

- Permissionless participation
- Open financial interaction
- Smart contract deployment
- EVM compatibility

## Technology Stack

- Solidity
- Remix IDE
- MetaMask
- OPN Testnet

## Deployment

Successfully compiled and deployed on OPN Testnet.

## Future Vision

Build transparent and accessible financial infrastructure.
